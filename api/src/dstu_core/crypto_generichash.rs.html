1//! `crypto_generichash` equivalent (`docs/dstu-crypto-project.md` "Mapping onto the libsodium API",
2//! `docs/TASKS.md` T-105, roadmap Step 3 item 2 - `docs/DECISIONS.md` D-66) - a bare re-export of
3//! [`crate::hazmat::kupyna`]'s one-shot and streaming API under this crate's top-level `crypto_*`
4//! namespace, for naming parity with `crypto_sign`/`crypto_secretbox`/`crypto_pwhash` rather than
5//! a new wrapper.
6//!
7//! Unlike those three modules, there is nothing here for a wrapper to add: `hazmat::kupyna`'s
8//! `digest()`/`Hasher` API already has no knob to hide (no algorithm choice beyond the output
9//! size, no nonce, no length cap) and libsodium's own `crypto_generichash` value-adds over a bare
10//! hash function - a caller-chosen variable output length, and an optional key for keyed hashing -
11//! have no DSTU equivalent to re-derive: Kupyna has no variable-length-output mode, and DSTU
12//! 7564:2014's own keyed construction is [`crate::hazmat::kupyna_kmac`], a distinct primitive
13//! surfaced separately as [`crate::crypto_auth`], not a parameter of this one. See D-66's fuller
14//! reasoning for why this module is a re-export rather than a table entry (discoverability under
15//! this crate's `crypto_*` namespace) and why it is a re-export rather than a wrapper with new
16//! logic (nothing left to wrap).
17//!
18//! # Example
19//!
20//! A hash gives a fixed-size fingerprint of a message - useful for checking a file wasn't
21//! corrupted or changed, but (unlike [`crate::crypto_auth`]) it needs no secret key, so anyone can
22//! compute or forge one; it is not proof of origin. One-shot for a whole in-memory message
23//! ([`Kupyna256::digest`]), or incremental via [`Kupyna256Hasher`] for a large/streamed one (e.g.
24//! `uacrypt hash`'s own chunked file reading) - both produce the same digest for the same bytes.
25//!
26//! ```rust
27//! use dstu_core::crypto_generichash::{Kupyna256, Kupyna256Hasher};
28//!
29//! let whole = Kupyna256::digest(b"hello world");
30//!
31//! let mut hasher = Kupyna256Hasher::new();
32//! hasher.update(b"hello ");
33//! hasher.update(b"world");
34//! let streamed = hasher.finalize();
35//!
36//! assert_eq!(whole, streamed);
37//! ```
38
39pub use crate::hazmat::kupyna::{Kupyna256, Kupyna256Hasher, Kupyna512, Kupyna512Hasher};
