1//! `crypto_secretbox` equivalent (`docs/dstu-crypto-project.md` "Mapping onto the libsodium API",
2//! `docs/TASKS.md` T-37, `docs/DECISIONS.md` D-51) - a single fixed `hazmat::kalyna_gcm::Kalyna256_256Gcm`
3//! construction (D-47's tie-breaker rule: no algorithm knob when one safe default exists) with an
4//! internally-generated nonce (never caller-supplied, extending the pattern `uacrypt kalyna-ccm
5//! encrypt`'s CLI layer already used, D-40/T-82) and a combined
6//! `version || nonce || ciphertext || tag` wire format, matching libsodium's own
7//! `crypto_secretbox_easy` ergonomics. The 1-byte version (currently `2`; 0.3.x blobs had none,
8//! T-232/D-202) lets a future format change fail with [`SecretboxError::UnsupportedVersion`]
9//! instead of an unexplained [`SecretboxError::TagMismatch`].
10//!
11//! # No message-length cap
12//!
13//! Migrated from Kalyna-CCM to Kalyna-GCM 2026-07-25 (roadmap Step 3 item 1, `docs/DECISIONS.md`
14//! D-63) - the original Kalyna-CCM construction capped plaintext/AAD at 255 bytes each (D-41,
15//! `ccm_padd`'s header encoding). GCM encodes no length into its construction at all, so that cap
16//! and `SecretboxError::MessageTooLong` are gone entirely, not just raised. This does not make
17//! disk-file encryption memory-bounded, though: an AEAD tag needs the full plaintext/ciphertext,
18//! so a large message still means a correspondingly large in-memory buffer (see `uacrypt`'s own
19//! `run_secretbox_command` doc comment for the concrete consequence at the CLI layer).
20//! `crypto_secretstream` (`docs/TASKS.md` T-40) remains the separately-tracked follow-up for a
21//! genuinely chunked/streaming construction; this module still does not attempt that.
22//!
23//! # No AAD (caller-facing) - but the version, nonce and length are bound into the tag internally
24//!
25//! libsodium's own `crypto_secretbox` has no associated-data parameter (that's `crypto_aead`'s
26//! job) - `hazmat::kalyna_gcm` takes AAD, but exposing it here would quietly turn this into a
27//! different primitive than its name promises. No caller-supplied AAD exists.
28//!
29//! Internally, though, `seal`/`open` pass the nonce itself as `kalyna_gcm`'s AAD (never empty).
30//! This is not optional: unlike NIST AES-GCM, DSTU 7624's Kalyna-GCM tag is computed purely from
31//! AAD and ciphertext (`E_K(accumulator XOR length_block)`, D-56 divergence 3) and never mixes in
32//! the IV/nonce at all - the nonce only seeds the keystream. For a combined
33//! `nonce || ciphertext || tag` blob, an unauthenticated nonce means an attacker can flip bits in
34//! the nonce prefix of a sealed message and `open` will still "succeed", just against a different
35//! (attacker-uncontrolled but unverified-as-original) keystream - a real tamper-evidence gap the
36//! previous CCM-based construction did not have (CCM's B0 formatting block ties the nonce into its
37//! CBC-MAC). Passing the nonce as AAD closes it using the construction's own designed mechanism
38//! for authenticating out-of-band data, the same way a caller would bind a header to an AEAD tag.
39//! Caught by `tampered_nonce_is_rejected` during this migration, not assumed - see `docs/DECISIONS.md`
40//! D-63.
41//!
42//! The internal AAD is `version || nonce || (ciphertext_len as u64).to_le_bytes()`. The length was
43//! added by T-232 (audit F-01, `docs/DECISIONS.md` D-200) because `kalyna_gcm` then tagged only the
44//! padded ciphertext length, so `ct` and `ct || 80 00..` shared a tag. Since T-234 (D-204)
45//! `kalyna_gcm` binds the true length itself, per DSTU 7624:2014 §12.2; the AAD keeps it as defence
46//! in depth, so this format never depends on one hazmat detail for that property.
47//!
48//! # Provenance
49//!
50//! Inherits `hazmat::kalyna_gcm`'s provenance: checked against DSTU 7624:2014 (draft edition) §12.2
51//! and its annex В.8 examples (T-234, D-204). Because this module's AAD is never block-aligned, its
52//! tags differ from what UAPKI or Bouncy Castle 1.85 would compute (`docs/COMPATIBILITY.md`).
53//! `Kalyna256_256Gcm` was chosen over the other four Kalyna-GCM variants as the sole construction
54//! here (256-bit key, matching the previous CCM construction's key/nonce width exactly) - see D-51
55//! for the fuller reasoning behind fixing one variant rather than exposing all five, including why
56//! the `Strength`-enum precedent from `crypto_pwhash` does not apply (a Kalyna variant is exactly the knob D-47 says to delete, not a
57//! genuine per-context tradeoff the caller must make). The 16-byte tag (truncated from GCM's own
58//! full 32-byte tag, via the same prefix-comparison convention `hazmat::kalyna_gcm`/`kalyna_gmac`
59//! already support) matches the previous construction's tag length and libsodium's own
60//! `crypto_secretbox` tag size - a fixed choice, not a new knob.
61//!
62//! # Example
63//!
64//! Encrypts a whole in-memory message under a freshly generated key. `seal`/`open` protect both
65//! confidentiality (nobody without the key can read the message) and integrity (`open` rejects
66//! anything tampered with, rather than returning wrong plaintext) - see below for the "tampered
67//! ciphertext is rejected" case, `docs/TASKS.md` T-120's own required failure-path example.
68//!
69//! ```rust
70//! use dstu_core::crypto_secretbox::{seal, open, SecretKey};
71//!
72//! let key = SecretKey::generate().expect("OS CSPRNG should not fail");
73//! let sealed = seal(&key, b"message").expect("OS CSPRNG should not fail");
74//! let opened = open(&key, &sealed).expect("authentic ciphertext");
75//! assert_eq!(opened, b"message");
76//!
77//! // Tampering with the sealed blob (ciphertext, tag, or nonce) is detected, not silently
78//! // "decrypted" into wrong plaintext.
79//! let mut tampered = sealed.clone();
80//! let last = tampered.len() - 1;
81//! tampered[last] ^= 1;
82//! assert!(open(&key, &tampered).is_err());
83//! ```

90/// Wire-format version, the blob's first byte (T-232; 0.3.x blobs had no version byte).
91const FORMAT_VERSION: u8 = 2;
92const NONCE_LEN: usize = 32;
93const HEADER_LEN: usize = 1 + NONCE_LEN;
94const TAG_LEN: usize = 16;
95
96/// `crypto_secretbox` can fail for reasons beyond a wrong key.
97#[derive(Debug)]
98pub enum SecretboxError {
99    /// The input to [`open`] is shorter than a version byte, a nonce and a tag (49 bytes) - too
100    /// short to have ever been produced by [`seal`].
101    Truncated,
102    /// Authentication failed: wrong key, or `sealed` was tampered with.
103    TagMismatch,
104    /// The input to [`open`] starts with a format version byte this build does not read - a blob
105    /// from an older or newer `crypto_secretbox` wire format, not a tampered one (the version byte
106    /// is public and also bound into the tag).
107    UnsupportedVersion,
108    /// The OS CSPRNG failed while generating a nonce (see [`crate::randombytes`]).
109    Random(RandomError),
110}
111
112impl fmt::Display for SecretboxError {
113    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
114        match self {
115            SecretboxError::Truncated => write!(f, "input too short to contain a nonce and tag"),
116            SecretboxError::TagMismatch => write!(f, "authentication failed"),
117            SecretboxError::UnsupportedVersion => write!(f, "unsupported secretbox format version"),
118            SecretboxError::Random(e) => write!(f, "{e}"),
119        }
120    }
121}
122
123impl core::error::Error for SecretboxError {}
124
125impl From<RandomError> for SecretboxError {
126    fn from(e: RandomError) -> Self {
127        SecretboxError::Random(e)
128    }
129}

131/// A `crypto_secretbox` key. Always exactly 32 bytes - `Kalyna256_256Ccm`'s key length, this
132/// module's one fixed construction (see the module doc).
133pub struct SecretKey([u8; 32]);
134
135impl Drop for SecretKey {
136    fn drop(&mut self) {
137        self.0.zeroize();
138    }
139}
140
141impl SecretKey {
142    /// Generates a fresh key from the OS CSPRNG - libsodium's `crypto_secretbox_keygen`
143    /// equivalent, so "how do I make a key" is never a caller decision.
144    ///
145    /// # Errors
146    ///
147    /// Returns [`SecretboxError::Random`] if the OS CSPRNG fails.
148    pub fn generate() -> Result<Self, SecretboxError> {
149        let mut bytes = [0u8; 32];
150        randombytes_buf(&mut bytes)?;
151        Ok(SecretKey(bytes))
152    }
153
154    #[must_use]
155    pub fn from_bytes(bytes: [u8; 32]) -> Self {
156        SecretKey(bytes)
157    }
158
159    #[must_use]
160    pub fn as_bytes(&self) -> &[u8; 32] {
161        &self.0
162    }
163}

165/// `version || nonce || ciphertext_len as u64 LE` - binds the version, the nonce (D-63) and the
166/// true ciphertext length into the tag. `hazmat::kalyna_gcm` binds the true length too since T-234
167/// (D-204); the copy here is defence in depth from T-232 (audit F-01, D-200).
168fn aad(nonce: &[u8; NONCE_LEN], ciphertext_len: usize) -> [u8; HEADER_LEN + 8] {
169    let Ok(len) = u64::try_from(ciphertext_len) else {
170        unreachable!("a slice length always fits in u64 on every supported target")
171    };
172    let mut aad = [0u8; HEADER_LEN + 8];
173    aad[0] = FORMAT_VERSION;
174    aad[1..HEADER_LEN].copy_from_slice(nonce);
175    aad[HEADER_LEN..].copy_from_slice(&len.to_le_bytes());
176    aad
177}

179/// Encrypts and authenticates `plaintext` under `key`, drawing a fresh random nonce internally.
180/// Returns `version (1 byte) || nonce (32 bytes) || ciphertext (plaintext.len() bytes) || tag (16
181/// bytes)` - no message-length cap (see the module doc comment).
182///
183/// # Errors
184///
185/// Returns [`SecretboxError::Random`] if the OS CSPRNG fails - the only way this can fail.
186pub fn seal(key: &SecretKey, plaintext: &[u8]) -> Result<Vec<u8>, SecretboxError> {
187    let mut nonce = [0u8; NONCE_LEN];
188    randombytes_buf(&mut nonce)?;
189
190    let cipher = Kalyna256_256Gcm::new(key.as_bytes());
191    let mut buf = vec![0u8; plaintext.len()];
192    let Ok(full_tag) = cipher.encrypt(&nonce, &aad(&nonce, plaintext.len()), plaintext, &mut buf)
193    else {
194        unreachable!("ciphertext_out.len() == plaintext.len() by construction")
195    };
196
197    let mut out = Vec::with_capacity(HEADER_LEN + buf.len() + TAG_LEN);
198    out.push(FORMAT_VERSION);
199    out.extend_from_slice(&nonce);
200    out.extend_from_slice(&buf);
201    out.extend_from_slice(&full_tag[..TAG_LEN]);
202    Ok(out)
203}

205/// Verifies and decrypts `sealed` (as produced by [`seal`]) under `key`.
206///
207/// # Errors
208///
209/// Returns [`SecretboxError::Truncated`] if `sealed` is shorter than a version byte, a nonce and a
210/// tag, [`SecretboxError::UnsupportedVersion`] if its version byte is not this build's format, or
211/// [`SecretboxError::TagMismatch`] if authentication fails (wrong key, or `sealed` was tampered
212/// with) - `sealed` is never partially trusted on a mismatch.
213pub fn open(key: &SecretKey, sealed: &[u8]) -> Result<Vec<u8>, SecretboxError> {
214    if sealed.len() < HEADER_LEN + TAG_LEN {
215        return Err(SecretboxError::Truncated);
216    }
217    if sealed[0] != FORMAT_VERSION {
218        return Err(SecretboxError::UnsupportedVersion);
219    }
220
221    let mut nonce = [0u8; NONCE_LEN];
222    nonce.copy_from_slice(&sealed[1..HEADER_LEN]);
223    let ciphertext_len = sealed.len() - HEADER_LEN - TAG_LEN;
224    let ciphertext = &sealed[HEADER_LEN..HEADER_LEN + ciphertext_len];
225    let tag = &sealed[HEADER_LEN + ciphertext_len..];
226
227    let cipher = Kalyna256_256Gcm::new(key.as_bytes());
228    let mut buf = vec![0u8; ciphertext_len];
229    cipher
230        .decrypt(&nonce, &aad(&nonce, ciphertext_len), ciphertext, tag, &mut buf)
231        .map_err(|e| match e {
232            GcmError::TagMismatch => SecretboxError::TagMismatch,
233            GcmError::InvalidLength | GcmError::EmptyInput => {
234                unreachable!(
235                    "tag.len() == TAG_LEN (16, within 8..=block_bytes) and plaintext_out.len()                      == ciphertext.len() by construction"
236                )
237            }
238        })?;
239    Ok(buf)
240}
