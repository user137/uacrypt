The passphrase file (docs/DECISIONS.md D-219, moved from uacrypt into the core by T-269): a 28-byte header in front of an ordinary stream file (D-208), so uacrypt encrypt --passphrase and every binding read and write the same bytes.

0x50 || 0x01 (container version) || 0x01 (Argon2id v1.3)
  || m_cost KiB (u32 LE) || t_cost (u32 LE) || p_cost (u8) || salt (16) || <stream file, D-208>

The stream key is derive_key(passphrase, salt, Moderate). The header carries no tag of its own: a changed salt gives another key and the first record fails, and a changed marker, version, KDF id or cost is refused by name. Only the costs seal_stream writes are accepted, and that check happens in Header::parse, before any Argon2 memory is allocated - a file cannot make its reader allocate 1 GiB. No oracle exists for the header: it is this project’s own format; derive_key itself equals libsodium’s crypto_pwhash.

use dstu_core::crypto_pwhash::passphrase_file::{seal_stream, Header, HEADER_BYTES};

let (mut enc, prefix) = seal_stream(b"correct horse battery staple")?;
let mut file = prefix.to_vec();
let mut record = [0u8; dstu_core::crypto_secretstream::MAX_RECORD_BYTES];
let n = enc.seal_final(b"short message", &mut record).expect("fits in one record");
file.extend_from_slice(&record[..n]);

let header = Header::parse(file[..HEADER_BYTES].try_into().expect("28 bytes"))?;
let decryptor = header.open_stream(b"correct horse battery staple")?;
// feed `decryptor` everything after the header (the stream-file codec's reader contract)

First byte of a passphrase file. A key-encrypted stream file starts with its own format version (2) instead, so a reader can tell the two apart from byte 0.
HEADER_BYTES
Length of the header in front of the stream file.
SEAL_STREAM_PREFIX_BYTES
The bytes seal_stream returns to write first: the header, then the stream file’s own version byte and header.

Functions§

seal_stream
Starts writing a passphrase file: draws a fresh salt, runs Argon2 (256 MiB, t=3), and returns the FileEncryptor for the records plus the SEAL_STREAM_PREFIX_BYTES-byte prefix to write first. Drive the encryptor as the stream-file codec documents.
