pub fn next_len(&self) -> usize

How many bytes FileDecryptor::feed wants next; 0 once finished or failed.

Source

pub fn feed( &mut self, input: &[u8], plaintext_out: &mut [u8], ) -> Result<usize, FileError>

Consumes exactly FileDecryptor::next_len bytes. Returns how many plaintext bytes it wrote to the start of plaintext_out (a verified non-final record), else 0.

§Errors

FileError::InvalidLength if input is not next_len() bytes or plaintext_out is shorter than CHUNK_BYTES (the call is then ignored); FileError::Finished after FileDecryptor::finish or an earlier error; otherwise the format or authentication error, after which the decryptor is failed.

Source

pub fn finish(&mut self, plaintext_out: &mut [u8]) -> Result<usize, FileError>

Call when the input ended before next_len() bytes arrived (drop any partial bytes). Returns the Final record’s plaintext length, written to plaintext_out.

§Errors

FileError::Truncated if no Final record verified yet; FileError::InvalidLength if plaintext_out is shorter than CHUNK_BYTES; FileError::Finished after an earlier finish or error.
