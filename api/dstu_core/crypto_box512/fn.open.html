pub fn open(sealed: &[u8], secret: &SecretKey) -> Result<Vec<u8>, OpenError>
Expand description

Decrypts sealed (as produced by seal or seal_stream) under secret - the in-memory form of open_stream. Partially decrypted plaintext is zeroized before an error returns.

§Errors

Returns OpenError::UnsupportedVersion if sealed’s first byte is not this build’s format version (a blob from 0.4-0.6 included - see open_v2_legacy), OpenError::Truncated if it is shorter than the minimum possible length or its stream ends before a verified Final record, or OpenError::InvalidCiphertext for any other failure - see the module doc’s “Error collapsing” section.
