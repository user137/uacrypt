pub fn hash_to_field(hash: &[u8]) -> FieldElement
Expand description

Same construction as signature::hash_to_field, widened to m=257/33 bytes: keep the hash’s last min(len, 33) bytes, masking the top byte to its low 1 bit if a full 33 were taken (257 bits total - 33*8 - 257 = 7 padding bits, so only bit 0 of the top byte is meaningful).
