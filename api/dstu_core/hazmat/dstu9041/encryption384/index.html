Encrypt/decrypt composition for DSTU 9041’s l(p)=384 case (T-297 - clauses 11/12, the clause set encryption.rs/encryption512.rs cite; docs/DECISIONS.md D-241/D-244).

Two differences from 256/512, both from the text:

  • The Kalyna-KW key is kappa = x_T^(k), the low-order k = 256 bits of x_T (clause 5.2; Table 2 gives Kalyna-256/256 for l(p)=384). At 256/512 k equals l(p), so all of x_T.
  • M' is 48 bytes, not a multiple of the 32-byte block, so t is Kalyna-256/256-KW-p over M' itself (DSTU 7624 §15.4, crate::hazmat::kalyna_kw_p). 256/512 wrap M' || 0^l with plain KW, the convention their worked examples confirmed (D-165/D-180).

Додаток Г.2 reproduces here up to kappa, H and M'; its printed t does not follow §15.4, so this module neither produces it nor accepts the document’s C (D-241, the owner’s choice).

DecryptError is collapsed to one variant, and point_from_x carries the Finding 1/2 guards (re-derived for E384/1 in D-241), as in encryption.rs/encryption512.rs.
