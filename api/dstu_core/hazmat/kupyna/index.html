Kupyna hash function (DSTU 7564:2014).

Ported from docs/pseudocode/kupyna.md (itself transcribed from the designers’ paper, docs/papers/Kupyna.pdf Sections 4-6) and structurally mirrors oracles/kupyna-reference/kupyna.c (Roman Oliynykov) byte-matrix-for-byte-matrix, rather than the T-table-fused optimization Bouncy Castle uses — deliberately, since this port could not be compiled or run locally (no Rust toolchain available; see .claude.local.md), and the more literal translation carries less risk of an unverifiable transposition bug. Full citation and verification status: docs/DECISIONS.md D-10.

Only byte-aligned messages are supported - the public API takes &[u8], which cannot express a bit-level length anyway. This matches the extracted test vectors exactly (see the note field in crates/dstu-core/tests/vectors/kupyna/*.json).
